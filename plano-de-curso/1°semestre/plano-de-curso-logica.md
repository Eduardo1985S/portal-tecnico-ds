# Plano de Curso: Lógica de Programação (20 Semanas)

Este plano de curso foi desenhado para introduzir alunos ao mundo da programação, começando pelos fundamentos teóricos da lógica, passando por pseudocódigo no VisuAlg, introduzindo versionamento com GitHub e migrando para uma linguagem de mercado (JavaScript) até a manipulação de arrays.

---

## 🎯 Módulo 1: Fundamentos da Lógica e Algoritmos

**Semana 1: Introdução à Lógica de Programação**
- O que é lógica e o que é lógica de programação?
- Como os computadores processam informações (Entrada, Processamento, Saída).
- O que são algoritmos? Exemplos de algoritmos no dia a dia (receitas, manuais).

**Semana 2: Representação Visual de Algoritmos**
- Introdução a Fluxogramas.
- Símbolos padrão e suas funções (início/fim, entrada de dados, saída, processo, decisão).
- Criação de fluxogramas simples para resolução de problemas básicos.

**Semana 3: Introdução ao Pseudocódigo**
- O que é pseudocódigo (Português Estruturado) e sua importância antes de codar.
- Variáveis e Tipos de Dados Básicos (Inteiro, Real, Caractere, Lógico).
- Como declarar e atribuir valores às variáveis.

**Semana 4: Operadores e Comandos de Entrada/Saída**
- Operadores aritméticos (`+`, `-`, `*`, `/`, `%`).
- Comandos de Entrada (`leia`) e Saída (`escreva` / `escreval`).
- Resolução de problemas matemáticos sequenciais em papel/texto.

---

## 💻 Módulo 2: Prática com VisuAlg

**Semana 5: Conhecendo o VisuAlg**
- Instalação e familiarização com a interface do VisuAlg.
- Estrutura básica de um algoritmo no VisuAlg.
- Operadores Relacionais (`>`, `<`, `>=`, `<=`, `=`, `<>`) e Lógicos (`E`, `OU`, `NAO`).

**Semana 6: Estruturas Condicionais (Parte 1)**
- Estrutura condicional simples (`se... entao`).
- Estrutura condicional composta (`se... entao... senao`).
- Práticas de tomada de decisão (ex: aluno aprovado/reprovado, par ou ímpar).

**Semana 7: Estruturas Condicionais (Parte 2)**
- Estruturas condicionais encadeadas (vários `se` dentro de `senao`).
- Estrutura de múltipla escolha (`escolha... caso`).
- Criação de menus interativos simples.

**Semana 8: Estruturas de Repetição (Parte 1)**
- O conceito de laços de repetição (loops) e para que servem.
- Estrutura `enquanto... faca`.
- Estrutura `repita... ate`.

**Semana 9: Estruturas de Repetição (Parte 2)**
- Estrutura `para... de... ate... faca`.
- Diferenças entre os tipos de laço e quando utilizar cada um.
- Contadores e Acumuladores.

**Semana 10: Estruturas de Dados Homogêneas (Vetores)**
- O que são Vetores (Arrays unidimensionais).
- Declaração, preenchimento e leitura de vetores no VisuAlg.
- Percorrendo vetores com a estrutura `para`.

---

## 🐙 Módulo 3: Versionamento de Código

**Semana 11: Introdução ao Git**
- O que é controle de versão e por que o mercado exige?
- Instalação e configuração inicial do Git.
- Primeiros comandos locais: `git init`, `git status`, `git add`, `git commit`.

**Semana 12: GitHub e Repositórios Remotos**
- O que é o GitHub? Criação de conta e perfil.
- Vinculando um repositório local a um repositório remoto (`git remote`).
- Enviando código (`git push`), recebendo atualizações (`git pull`) e clonando (`git clone`).

---

## 🚀 Módulo 4: Migração para o JavaScript

**Semana 13: Introdução ao JavaScript e Ambiente de Desenvolvimento**
- O que é JavaScript? Diferença entre JS no navegador e no Node.js.
- Configurando o ambiente de desenvolvimento (VS Code e Node.js).
- Sintaxe básica: declarando variáveis (`let` e `const`) e exibindo dados (`console.log`).

**Semana 14: Operadores e Tipos de Dados no JS**
- Tipos de dados em JS (`Number`, `String`, `Boolean`).
- Operadores JS (`+`, `-`, `==`, `===`, `!=`, `!==`, `&&`, `||`, `!`).
- Entendendo a diferença entre `=` (atribuição) e `==`/`===` (comparação).
- Primeiros commits em JS no GitHub.

**Semana 15: Estruturas Condicionais no JS**
- Traduzindo o `se... senao` para `if... else if... else`.
- Traduzindo o `escolha... caso` para `switch... case`.
- Prática: Refatorando exercícios do VisuAlg para JavaScript.

**Semana 16: Estruturas de Repetição no JS**
- Traduzindo os laços do VisuAlg para o JavaScript: `while` e `do... while`.
- Entendendo o funcionamento do laço `for` (`for (let i = 0; i < 10; i++)`).

**Semana 17: Vetores (Arrays) no JavaScript**
- O que são arrays em JS (declaração com `[]`).
- Acessando e modificando elementos via índice.
- Diferença entre variáveis simples (primitivas) e arrays (referência).

**Semana 18: Iteração sobre Arrays no JS**
- Percorrendo arrays usando o laço `for` tradicional.
- Entendendo a propriedade `.length` em conjunto com estruturas de repetição.
- Percorrendo arrays de forma moderna com o laço `for...of`.

**Semana 19: Manipulação de Arrays e Git**
- Métodos essenciais para lidar com dados: `.push()` (adicionar no final) e `.pop()` (remover do final).
- Outros métodos úteis (ex: `.splice()` ou `.unshift()`).
- Prática: Construir pequenos algoritmos manipulando arrays e salvar tudo no repositório do GitHub com `git commit` e `git push`.

---

## 🎓 Módulo 5: Fechamento

**Semana 20: Revisão Geral e Projeto Final**
- **Revisão:** Resumo dos conceitos (Variáveis, Condicionais, Laços de Repetição e Arrays).
- **Projeto Prático Integrador:** Criação de um pequeno sistema apenas no terminal/console (Ex: Gerenciador de tarefas (To-Do List) ou um Sistema de Cadastro de Notas de Alunos).
- O projeto deverá ser comitado e enviado para o GitHub de forma organizada, solidificando o fluxo completo de desenvolvimento.
