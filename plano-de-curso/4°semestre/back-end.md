# Plano de Curso - Desenvolvimento Back-End (4º Semestre)

**Carga horária:** 40 Semanas
**Foco:** Fundamentos de Node.js, JavaScript ES6+, POO, Arquitetura MVC, APIs RESTful com Express, Persistência de Dados, Banco de Dados, Autenticação JWT e Projeto Integrador.
**Ferramentas:** Node.js, Express, JavaScript, VS Code, Git, GitHub, Postman, Swagger, Zod, JWT.

---

### Módulo 1: Fundamentos da Web, JavaScript e POO (Semanas 1 a 8)
- **Semana 01:** Introdução à Web e Arquitetura Back-End
  - Internet, Web, Front-End x Back-End e fluxos de dados.
- **Semana 02:** Preparação do Ambiente
  - Instalação e configuração do Node.js, VS Code, Terminal e NPM.
- **Semana 03:** Revisão de JavaScript ES6+
  - Sintaxe moderna e conceitos essenciais do ES6+.
- **Semana 04:** Manipulação de Arrays
  - Métodos avançados de array: `map`, `filter`, `find` e `reduce`.
- **Semana 05:** Funções e Modularização
  - Declaração de funções, callbacks e modularização de código.
- **Semana 06:** Introdução à Orientação a Objetos (POO)
  - Objetos JavaScript, classes, atributos e métodos.
- **Semana 07:** POO Avançado e Modelagem UML
  - Conceitos de Encapsulamento, Herança e elaboração de Diagramas de Classe (UML) para modelar o sistema.
- **Semana 08:** Versionamento e Código Limpo
  - Uso do Git, GitHub e aplicação de técnicas de Clean Code.

### Módulo 2: APIs RESTful com Express e MVC (Semanas 9 a 20)
- **Semana 09:** Protocolo HTTP e Métodos
  - Requisições, respostas, status codes e métodos HTTP (GET, POST, etc.).
- **Semana 10:** JSON na Prática
  - Tipos de dados, formatação e manipulação de coleções JSON.
- **Semana 11:** Introdução ao Express e MVC
  - Configuração do Express, roteamento básico e padrão de desenvolvimento MVC (Model-View-Controller).
- **Semana 12:** Rotas e Parâmetros
  - Rotas, parâmetros e definição clara de entradas e saídas (Requests/Responses).
- **Semana 13:** Middlewares e Tratamento de Erros
  - Criação de middlewares no Express e tratamento de erros.
- **Semana 14:** Primeira API RESTful
  - Construção da primeira API REST completa (sem persistência).
- **Semana 15:** Documentação de APIs
  - Utilização do Postman e Swagger para testar e documentar as rotas construídas.
- **Semana 16:** CRUD em Memória
  - Implementação de operações CRUD em memória com validação das regras de negócio.
- **Semana 17:** Persistência Local em JSON
  - Persistência de dados local salvando e manipulando arquivos JSON.
- **Semana 18:** Consolidação e Refatoração
  - Semana de consolidação, tira-dúvidas, refatoração de código e tempo extra para finalização de APIs.
- **Semana 19:** Projeto Integrador Parcial
  - Entrega da API documentada (Swagger/Postman), estruturada em MVC e persistindo dados localmente em JSON.
- **Semana 20:** Refinamento e Encerramento da 1ª Etapa
  - Refinamento final do projeto e encerramento da primeira etapa.

### Módulo 3: Arquitetura Avançada e Banco de Dados (Semanas 21 a 27)
- **Semana 21:** Organização Profissional de Projetos
  - Revisão, refatoração dos projetos e organização profissional de projetos Node.js.
- **Semana 22:** Arquitetura em Camadas e Design Patterns
  - Arquitetura em camadas: Padrão MVC (Routes, Controllers e Services) e Design Patterns.
- **Semana 23:** Clean Code Aplicado ao Node.js
  - Clean Code aplicado ao JavaScript e boas práticas estruturais.
- **Semana 24:** Middlewares Avançados e Validação
  - Tratamento de erros, middlewares avançados e validação de dados (ex: Zod, Joi).
- **Semana 25:** Persistência e Modelagem de Banco de Dados
  - Persistência de dados: conexão e modelagem de banco de dados (MER/DER).
- **Semana 26:** CRUD Conectado ao Banco de Dados
  - Operações com banco: CRUD completo conectado à arquitetura em camadas.
- **Semana 27:** Banco de Dados Avançado e Consultas
  - Relacionamentos entre tabelas/coleções e consultas avançadas.

### Módulo 4: Segurança, Recursos Avançados e Projeto Final (Semanas 28 a 40)
- **Semana 28:** Segurança e Hashing de Senhas
  - Autenticação básica e hashing de senhas para os usuários do banco.
- **Semana 29:** Autenticação Avançada com JWT
  - Geração e validação de tokens JWT.
- **Semana 30:** Autorização e Controle de Acesso
  - Controle de acesso por perfil (Admin vs. Cliente).
- **Semana 31:** Otimização e Paginação
  - Paginação, filtros e buscas no banco de dados.
- **Semana 32:** Transferência de Arquivos
  - Upload de imagens/arquivos (armazenamento local ou nuvem).
- **Semana 33:** Sistema de Notificações
  - Mecanismos de envio de mensagens e notificações entre cliente e servidor.
- **Semana 34:** Integração com APIs Externas
  - Consumo e integração com APIs externas.
- **Semana 35:** Consolidação e Nivelamento
  - Apoio para absorver consultas avançadas ou a configuração do JWT.
- **Semana 36:** Planejamento do Projeto Final
  - Tradução de regras de negócio em lógica e separação de tarefas.
- **Semana 37:** Desenvolvimento do Projeto Final (Parte 1)
  - Acompanhamento e mentoria prática do projeto final.
- **Semana 38:** Desenvolvimento do Projeto Final (Parte 2)
  - Continuidades do desenvolvimento e mentoria prática.
- **Semana 39:** Consolidação, Testes e Caça aos Bugs
  - "Caça aos Bugs" no projeto final e preparação para o ambiente de produção.
- **Semana 40:** Publicação (Deploy) e Apresentação Final
  - Publicação (Deploy), apresentação da API documentada e encerramento.
