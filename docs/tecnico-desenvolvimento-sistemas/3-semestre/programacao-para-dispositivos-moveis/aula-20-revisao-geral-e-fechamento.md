## Aula 20 — Revisão Geral e Fechamento

## <i className="fa-solid fa-bullseye" style={{ color: 'var(--ifm-color-primary)' }}></i> Objetivo da aula

Consolidar todo o aprendizado de React Native, componentes estruturais, estilização, listas, estados e navegação realizando um **desafio técnico real** simulando uma contratação de mercado.

## <i className="fa-solid fa-book" style={{ color: 'var(--ifm-color-primary)' }}></i> Conteúdos trabalhados

- Revisão teórica rápida dos conceitos fundamentais do 3º Semestre.
- Lançamento do Desafio Técnico Integrador final.
- Boas práticas de documentação e entrega de projetos profissionais.

## <i className="fa-solid fa-brain" style={{ color: 'var(--ifm-color-primary)' }}></i> Explicação

Chegou a hora de provar suas habilidades! Nas últimas 19 semanas, você aprendeu a configurar o Expo, criar telas dinâmicas, usar estilos com StyleSheet, manipular estados locais e estruturar navegações profissionais. 

No mercado de trabalho real, o processo de seleção para uma vaga de desenvolvedor júnior geralmente envolve a resolução de um **desafio técnico prático**. Você recebe uma especificação e tem um prazo curto para entregar um aplicativo funcionando.

Como fechamento do nosso semestre, propomos que você resolva um teste real projetado pela DevStart Mobile.

## <i className="fa-solid fa-laptop-code" style={{ color: 'var(--ifm-color-primary)' }}></i> Desafio Técnico Real

Você deve realizar um fork e resolver o teste técnico completo detalhado em:
👉 **[teste-tecnico-dev-jr-mobile](https://github.com/Eduardo1985S/teste-tecnico-dev-jr-mobile)**

### Requisitos do Projeto
O aplicativo deve ser um **portfólio do próprio aluno** simulando um candidato a vaga de desenvolvedor mobile júnior, contendo:
1. **Navegação em Abas (TabBar):** Pelo menos 3 telas de navegação inferiores.
2. **Tela Perfil:** Nome, imagem profissional (local ou remota), cargo e seção "Sobre mim".
3. **Tela Habilidades:** Lista interativa com pelo menos 5 habilidades de desenvolvimento.
4. **Tela Projetos e Contato:** Descrição de 2 projetos executados e uma área com campos de entrada de dados (`TextInput`) para o visitante enviar uma mensagem de contato profissional.

*Atenção: Não é permitida a utilização de bibliotecas de componentes prontos (como NativeBase ou Paper). Toda a interface deve ser criada do zero por você usando StyleSheet!*

## <i className="fa-solid fa-flask" style={{ color: 'var(--ifm-color-primary)' }}></i> Atividade prática

1. Acesse o repositório do desafio técnico: [teste-tecnico-dev-jr-mobile](https://github.com/Eduardo1985S/teste-tecnico-dev-jr-mobile).
2. Faça um **Fork** do repositório para a sua conta pessoal do GitHub.
3. Clone o seu fork na sua máquina.
4. Inicialize o projeto Expo com `npx create-expo-app@latest perfil-dev-jr --template blank` dentro da pasta clonada.
5. Crie a estrutura de pastas sugerida: `screens/`, `assets/`.
6. Desenvolva as telas do aplicativo com capricho visual, mantendo um design harmônico e profissional.
7. Escreva um arquivo `README.md` incrível explicando a arquitetura do seu app e como rodá-lo.
8. Envie os commits finais para o seu repositório e compartilhe o link público com o professor!

## <i className="fa-solid fa-list-check" style={{ color: 'var(--ifm-color-primary)' }}></i> Checklist de entrega

- [ ] O projeto foi forkado e versionado de forma correta no GitHub pessoal.
- [ ] O aplicativo usa navegação por abas inferior funcional.
- [ ] Todas as 3 telas solicitadas estão implementadas de forma visualmente rica e responsiva.
- [ ] Nenhum framework de UI de mercado foi utilizado (estilização 100% via StyleSheet próprio).
- [ ] O arquivo README está completo contendo prints, tecnologias e passos de execução.

## <i className="fa-solid fa-rocket" style={{ color: 'var(--ifm-color-primary)' }}></i> Agora é com você!

Essa é a sua chance de se destacar e sair na frente no mercado! Trate esse desafio técnico como se fosse a sua grande oportunidade profissional. Capriche nos estilos, implemente micro-interações, use um tema visual elegante e capriche no portfólio. A sua capacidade de documentar e apresentar soluções é tão valiosa quanto as linhas de código que você escreve. Boa sorte, desenvolvedor! 🚀
