# Aula 20 — Revisão Geral e Projeto Final

## <i className="fa-solid fa-bullseye" style={{ color: 'var(--ifm-color-primary)' }}></i> Objetivo da aula

Revisar todos os conceitos aprendidos no semestre construindo um Projeto Final avaliativo: um mini-sistema gerenciador em JavaScript rodando no terminal.

## <i className="fa-solid fa-book" style={{ color: 'var(--ifm-color-primary)' }}></i> Conteúdos trabalhados

- Variáveis, Operadores, Condicionais e Laços de repetição.
- Arrays e Iteração.
- Versionamento com Git e GitHub.

## <i className="fa-solid fa-brain" style={{ color: 'var(--ifm-color-primary)' }}></i> Explicação

### O que faz um sistema de verdade?
Sistemas reais nada mais são do que grandes blocos de código que guardam dados (Arrays), tomam decisões baseadas no que o usuário clica/digita (Ifs e Switches) e repetem tarefas para exibir listas inteiras na tela (Loops). O desafio de hoje é juntar todas essas peças de LEGO que aprendemos até aqui.

Você criará o seu próprio sistema de gerenciamento interativo usando JavaScript!

## <i className="fa-solid fa-flask" style={{ color: 'var(--ifm-color-primary)' }}></i> O Projeto: Gerenciador de Tarefas (To-Do List)

O seu objetivo final no semestre é programar um **Gerenciador de Tarefas**. 

*(Como no Node.js puro é difícil ter um menu interativo que para o código esperando digitação, nós vamos programar a "Lógica por trás das telas", também chamada de Regras de Negócio).*

Você deve criar um arquivo `projetoFinal.js` e implementar:
1. Um **Array** chamado `tarefas` inicialmente vazio.
2. Criar uma série de operações simuladas em código:
   - Cadastrar três tarefas novas (usando `.push()`).
   - Fazer um laço `for` ou `for...of` que imprima a lista inteira de forma bonita no console. Ex: `[1] Comprar pão`, `[2] Estudar JS`.
   - Utilizar uma lógica de `if` para buscar se uma tarefa específica existe no array (ex: buscar se "Estudar JS" está na lista).
   - Remover uma das tarefas.
   - Imprimir a lista final.

Ao finalizar tudo, você deve enviar o projeto para o **GitHub**.

## <i className="fa-solid fa-list-check" style={{ color: 'var(--ifm-color-primary)' }}></i> Critérios de Avaliação (Checklist de entrega)

- [ ] O arquivo `projetoFinal.js` está bem organizado e possui comentários explicativos.
- [ ] O aluno declarou as variáveis corretamente (uso de `let` e `const`).
- [ ] Operações de adição de elementos (Array Push) foram realizadas.
- [ ] Existe pelo menos uma estrutura de repetição (`for` ou `while`) imprimindo a lista de tarefas.
- [ ] O projeto encontra-se em um repositório público no GitHub.
