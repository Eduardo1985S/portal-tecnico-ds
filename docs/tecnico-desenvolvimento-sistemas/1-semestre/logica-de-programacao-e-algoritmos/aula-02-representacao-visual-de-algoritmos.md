# Aula 02 — Representação Visual de Algoritmos

## <i className="fa-solid fa-bullseye" style={{ color: 'var(--ifm-color-primary)' }}></i> Objetivo da aula

Entender a importância da representação visual na lógica de programação e aprender a utilizar fluxogramas para desenhar a solução de problemas.

## <i className="fa-solid fa-book" style={{ color: 'var(--ifm-color-primary)' }}></i> Conteúdos trabalhados

- Introdução aos Fluxogramas.
- Principais símbolos (Início/Fim, Processo, Decisão, Entrada/Saída).
- Como desenhar soluções lógicas através de formas geométricas.

## <i className="fa-solid fa-brain" style={{ color: 'var(--ifm-color-primary)' }}></i> Explicação

### Por que desenhar um algoritmo?
Antes de escrevermos códigos em telas pretas com letras coloridas, precisamos saber visualizar a solução de um problema. Um **fluxograma** é uma representação gráfica (um desenho) de um algoritmo. Ele ajuda a ver claramente qual caminho a informação está percorrendo do início ao fim.

### Os Símbolos de um Fluxograma
Para que qualquer pessoa do mundo entenda o seu desenho, utilizamos formas geométricas padronizadas:
1. **Elipse (Terminal):** Indica o Início e o Fim do algoritmo.
2. **Retângulo (Processamento):** Indica uma ação ou cálculo que está sendo feito (ex: `somar notas`).
3. **Losango (Decisão):** Indica uma pergunta onde o fluxo pode se dividir em dois caminhos, geralmente "Sim" ou "Não" (ex: `A nota é maior que 7?`).
4. **Paralelogramo (Entrada/Saída):** Indica o momento em que o usuário insere um dado ou o sistema exibe uma informação na tela.
5. **Setas:** Conectam os símbolos e mostram a direção em que o algoritmo está rodando.

## <i className="fa-solid fa-laptop-code" style={{ color: 'var(--ifm-color-primary)' }}></i> Exemplo prático

Imagine o fluxograma para o algoritmo **"Sair de casa com chuva"**:
1. **[Início]** (Elipse)
2. **[Olhar pela janela]** (Retângulo de processo)
3. **[Está chovendo?]** (Losango de decisão)
   - Se **Sim**: Segue para o passo 4.
   - Se **Não**: Pula para o passo 5.
4. **[Pegar guarda-chuva]** (Retângulo)
5. **[Sair de casa]** (Retângulo)
6. **[Fim]** (Elipse)

## <i className="fa-solid fa-flask" style={{ color: 'var(--ifm-color-primary)' }}></i> Atividade prática

Agora, pegue uma folha de papel e desenhe um fluxograma para a seguinte situação: **"Comprar um refrigerante na máquina"**.

Lembre-se de colocar as etapas: inserir dinheiro, escolher a bebida e a verificação (decisão) se o dinheiro foi suficiente. Use os símbolos corretos (elipse, retângulo, losango).

## <i className="fa-solid fa-list-check" style={{ color: 'var(--ifm-color-primary)' }}></i> Checklist de entrega

- [ ] O fluxo possui um Início e um Fim claros (usando elipses).
- [ ] As setas apontam para a direção correta do fluxo.
- [ ] O aluno utilizou um losango para tomar uma decisão (ex: dinheiro é suficiente?).
- [ ] O problema foi resolvido de forma lógica no desenho.

## <i className="fa-solid fa-rocket" style={{ color: 'var(--ifm-color-primary)' }}></i> Agora é com você!

Para dominar a lógica de programação, a prática constante é fundamental! Assuma o controle do seu aprendizado: escolha outro processo do seu dia a dia (como decidir o que almoçar ou atravessar um semáforo) e desenhe o fluxograma dessa ação. 

Desafie um colega a analisar o seu desenho para ver se ele faz sentido. Lembre-se: desenhar o problema antes de tentar resolvê-lo no computador é uma das habilidades mais valorizadas em desenvolvedores experientes!
